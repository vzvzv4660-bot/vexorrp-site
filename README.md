# VEXOR RP — GitHub Pages

Это готовая статическая версия сайта. Дизайн, страницы, стили, изображения, переключатель темы и каталог магазина сохранены. Кнопки «ПРИОБРЕСТИ» ведут на https://t.me/vexorrp.

## Как опубликовать сайт

1. Создай новый репозиторий на https://github.com/new (например, `vexor-rp-site`).
2. Распакуй архив и загрузи **все файлы и папки из этой папки** в корень репозитория. Файл `index.html` должен лежать прямо в корне, а не во вложенной папке.
3. Открой репозиторий → **Settings** → **Pages**.
4. В разделе **Build and deployment** выбери **Deploy from a branch**.
5. Выбери ветку **main** и папку **/(root)**, затем нажми **Save**.
6. Через несколько минут GitHub покажет адрес опубликованного сайта в разделе Pages.

## Важно

- Это статический сайт: GitHub Pages не запускает PHP, Node-серверы или базы данных. В текущей версии для страниц сайта серверная часть не требуется.
- Для работы Google Fonts требуется подключение к интернету; если шрифт недоступен, браузер использует запасной.
- Форум, внешний сайт загрузки Connect и Telegram остаются внешними ссылками, как в исходной версии.
- В магазине переход к покупке открывает Telegram `@vexorrp`; оплата и автоматическая выдача товаров не реализованы самим GitHub Pages.
