VEXOR RP — SEO update

Что обновлено:
- Уточнены title и description главной страницы для запросов VEXOR RP, VEXOR, Вексор и Вексор РП.
- Добавлены варианты названия в структурированные данные WebSite.
- Добавлено естественное описание проекта на видимой главной странице.
- Существующие robots.txt и sitemap.xml сохранены.

Как опубликовать:
1. Распакуйте архив.
2. Загрузите ВСЁ содержимое в корень GitHub-репозитория, заменив старые файлы.
3. Нажмите Commit changes и дождитесь публикации GitHub Pages.
4. В Google Search Console откройте проверку URL https://vexorplay.online/ и нажмите «Запросить индексирование». Sitemap уже указан в robots.txt; если он ранее отправлялся, повторно добавлять его не требуется.
5. Добавьте и подтвердите https://vexorplay.online/ в Яндекс Вебмастере и отправьте sitemap https://vexorplay.online/sitemap.xml.

Важно: SEO не гарантирует первое место или мгновенное появление по каждому запросу. Поисковым системам нужно время на обход и оценку сайта.
